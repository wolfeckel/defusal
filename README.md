# Defusal

A bomb-defusal training game. The whole game is in `index.html`: inline CSS and JS, sounds synthesized with Web Audio. The only external dependency is Google Fonts.

## Development

```sh
npm install
npm run dev     # serves at http://localhost:5173 and reloads when you save
```

You can also just open `index.html` in a browser.
